## Netzwerk verbindung NAT/Bridged

- ### Ip Adressen Bridged

```sh
  kali: 192.168.1.52
  
  metasploitable: 192.168.1.51
  
  Host: 192.168.1.50
  
  St. Gateway: 192.168.1.50
```

- ### IP Adressen NAT

```sh
 kali: 192.168.40.142
 
 metasploitable: 192.168.40.147
 
 Host:192.168.40.1
 
 Kein St. Gateway
 ```

### *Unterschied*
- _Bridge:_ Die verbindung läuft über Ethernet 2 des Host. Dabei wird ein virtueller Switch verwendet.
- _NAT:_ VMWare Network VMnet 8. Es funktoniert wie ein virteller router. Verbindungen von außen Startet ist nicht möglich.

## Datenübertragung Meta -> Kali (Web server)

### Webserver: apache2

Zuerst wird kontrolliert, ob der Apache2 Webserver aktiv ist.

```sh
$ ps ax
```
- Apache2 Webserver lauft

  
```sh
$ sudo netstat -tlpn | grep apache
```
- Apache2 benutzt den Port 80

- Standart Verzeichniss: /var/www/test/

- Datei Anlegen
```
echo Hallo | sudo tee Hallo.txt
```

- Datei in Kali herunterladen

```
curl 192.168.40.147/test/Hallo.txt > Hallo.txt
```
